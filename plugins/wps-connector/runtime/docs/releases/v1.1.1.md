# WPS Connector v1.1.1

Frozen on 2026-07-19.

## Included

- Retains the stable per-document pane and binding behavior from v1.0.89.
- Anchors MCP document operations to the trusted current Codex task identity.
- Rejects caller-supplied task or project fields that conflict with trusted MCP
  metadata.
- Prevents a document bound to another Codex task from being selected or
  modified by reusing its session and binding identifiers.
- Adds regression coverage for missing trusted context, binding override
  attempts, and current-task session recommendation.

## Verified

- `npm run check`
- `npm test`
- Source and packaged runtime mirrors are identical.
- Cross-task write attempts return `CALLER_BINDING_OVERRIDE_REFUSED` or
  `SESSION_BINDING_MISMATCH` before reaching the document operation.
