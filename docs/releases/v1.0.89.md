# WPS Connector v1.0.89

Frozen on 2026-07-19.

## Included

- Stable per-document session anchoring for WPS Writer and Spreadsheet panes.
- Separate project and Codex task bindings for independently opened documents.
- Pane routing fixed to the immutable `sessionId`, `documentKey`, and `host`
  captured when the pane opens.
- Original WPS TaskPane creation, storage, and native close behavior retained to
  avoid the ghosting regression seen in window-follow experiments.

## Scope

- Moving an already-open document to another WPS window does not move its
  existing TaskPane.
- Cross-window TaskPane migration remains disabled because the supported WPS
  API does not provide a reliable reparent operation.
